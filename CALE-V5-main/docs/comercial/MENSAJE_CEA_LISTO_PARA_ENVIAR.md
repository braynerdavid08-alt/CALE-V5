## Tip para la demo (uso interno)

1. Entrar como escuela → Operación → **Reporte del día** (descarga directa) o `/school/reports`.  
2. Abrir el Excel: hojas de teoría / manejo / examen con estudiante, cédula y celular.  
3. Mostrar panel del aprendiz (simulacro + Kazu) y un aula en vivo o presentación del instructor.  
4. No prometer envío automático por WhatsApp Business API ni pagos electrónicos definitivos hasta cerrar legales y costos.
